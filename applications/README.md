# Applications

Per-job working notes and tailoring material. One folder per application, so
each job's assessment, source facts, and planned CV/cover-letter changes stay
together and can be reused as a reference when we actually edit the CV.

## Convention

```
applications/
  <employer>-<role-slug>-<year>/
    notes.md        # living document: fit assessment, source facts, gaps, action items
    posting.pdf     # (optional) the job posting, for reference
    ...             # (optional) tailored CV variants, cover-letter drafts
```

## How the notes files are used

- `notes.md` is a **living document** — updated continuously during a
  conversation as new facts, decisions, and clarifications come up.
- It is the single reference we consult before making any actual change to the
  CV or writing a cover letter.
- Facts recorded here follow the same rule as the CV: nothing invented. Items
  needing confirmation are marked **[VERIFY]**; questions still open are under
  **Open questions**.
- Nothing in this folder is `\input` by the CV or compiled — it is pure
  scratch/reference material.
